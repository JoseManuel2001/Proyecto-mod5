# ByGaby Studio

Landing/ecommerce inicial creada con React + Webpack.

## Ejecutar

```bash
npm install
npm run dev
```

Webpack abrirá el proyecto en http://localhost:3000.

## Build

```bash
npm run build
```

## Estructura

- `src/index.js` — componentes React y datos de productos.
- `src/styles.css` — diseño responsive.
- `src/assets/` — fotografías de productos preparadas para la tienda.
- `webpack.config.js` — configuración de Babel, CSS, imágenes y dev server.

Las imágenes originales tenían fondo de tela y etiquetas de precio; se prepararon versiones con fondo neutro para integrarlas en las tarjetas del catálogo.
